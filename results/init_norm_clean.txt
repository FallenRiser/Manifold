SECTION 6: Layer normalisation
==========================================================================
LayerNorm normalises across features (within a sample), not across batch.
This means it works with batch size 1 and with sequences.

Conceptual comparison:
  BatchNorm: for each feature, normalise across the batch dimension
  LayerNorm: for each sample, normalise across the feature dimension
  GroupNorm: for each sample, normalise across groups of features

SECTION 8: Breaking symmetry
==========================================================================
Why zero init fails and why random init is necessary.

Zero init:
  layer 1: all outputs identical=False, all zero=1
  layer 2: all outputs identical=False, all zero=1
  layer 3: all outputs identical=False, all zero=1
  layer 4: all outputs identical=False, all zero=1
  -> All units compute the same thing. Gradient is identical for every unit.
  -> They remain identical forever. The network has effective width 1.

Tiny random init (scale=0.001):
  layer 1: activation std=0.000513
  layer 2: activation std=0.000001
  layer 3: activation std=0.000000
  layer 4: activation std=0.000000
  -> Different but tiny. Symmetry is broken but gradients vanish.

He init:
  layer 1: activation std=0.5128
  layer 2: activation std=0.4326
  layer 3: activation std=0.5300
  layer 4: activation std=0.4879
  -> Healthy variance. Each unit computes something different.
